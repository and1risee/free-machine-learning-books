# Contributing

Thanks for your interest in improving this collection!

## Rules

1. ✅ Only add books with **legal free access** (open-access PDFs, author-shared files, free official online versions).
2. ❌ Never add pirated PDFs, shady download links, or torrent links.
3. ✅ Verify the link works before submitting.
4. ✅ Follow the existing table format:

| 📕 Book | 🖊 Author | 🔗 Link | 🏷 Level |
|---------|----------|---------|----------|

Levels: `Beginner`, `Intermediate`, `Advanced`, `All levels`.

## How to contribute

1. Fork the repo
2. Add your book to the appropriate section in `README.md`
3. Open a Pull Request with the title: `Add: [Book Name]`
